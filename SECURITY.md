# Sicherheitsrichtlinie

## Unterstützte Versionen

Sicherheitskorrekturen werden für die jeweils neueste veröffentlichte Version
bereitgestellt.

## Schwachstellen melden

Bitte sicherheitsrelevante Details nicht zuerst als öffentliches Issue
veröffentlichen. Verwende stattdessen GitHubs Funktion **Report a
vulnerability** im Bereich *Security Advisories* dieses Repositorys.

Eine gute Meldung enthält betroffene Version, Plattform, reproduzierbare
Schritte, mögliche Auswirkungen und – falls vorhanden – einen minimalen
Korrekturvorschlag. Empfang und Bewertung werden zeitnah bestätigt.

Wissenschaftliche Meinungsverschiedenheiten oder Modellkritik sind keine
Sicherheitslücken und können regulär als Issue diskutiert werden.
